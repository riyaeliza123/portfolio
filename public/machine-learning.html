Overview

My work in machine learning and computer vision focuses on building models that function reliably beyond research notebooks and into real-world use. I design, train, evaluate, and deploy end-to-end ML systems that replace manual workflows, scale monitoring efforts, and support faster, more consistent research.

I specialize in image-based modeling for monitoring applications, including wildlife, pinnipeds, and vessel detection. My goal is to bridge the gap between theory and practice by delivering machine learning products that are practical, understandable, and ready to use.

Projects and Impact

1. Pinniped Census via Drone Imagery (YOLOv11)

Sep 2025 – Dec 2025

Problem

Counting pinnipeds from on-shore cameras and drone imagery was slow and labor-intensive. Researchers had to manually review thousands of images per site, making census updates time-consuming and prone to error. A faster, scalable solution was needed to automate detection while keeping results accessible to the team.

Data

  • 618 images collected across Campbell River, Nanaimo, and Cowichan (Vancouver Island, Canada)
  • Preprocessed via augmentation and resizing for robust model training
  • Images captured from drones (multiple flights) and integrated with on-site census locations

Solution

  • Trained a YOLOv11 model to automatically detect and count pinnipeds with high accuracy along with a Streamlit interface where users can upload images, view annotated detections, and download per-image or per-location counts
  • Integrated temporary cloud storage (S3) for image processing and connected outputs to ODK databases for easy submission
  • Packaged as a deployable, self-contained tool, allowing non-technical researchers to run full analyses without touching code

Model Performance

  • Precision: 94.4%, Recall: 72.7%, Accuracy: 80%
  • False positive rate: ~7.5%, AUC: 0.83
  • Confusion matrix demonstrates strong discrimination ability and reliability for practical use

Impact

  • Reduced manual census effort from ~1 week per site to under 10 minutes
  • Fully deployed tool actively used by PSF researchers, enabling faster, more reliable pinniped monitoring

Focus

Computer vision, object detection, end-to-end ML product, deployment for real-world use

Tools

Python, YOLOv11, Streamlit, S3, ODK, Docker

2. Web-based Skin Anomaly Classification (DenseNet)

Jan 2023 – May 2023

Problem

Accurate and timely detection of skin anomalies is challenging, with multiple disease types that require expert evaluation. The goal was to build a real-time tool that assists users in identifying potential skin conditions from images, supporting faster decision-making.

Data

  • 6,021 labeled images across 11 skin disease classes (0–10)
  • Images split into training, validation, and test sets
  • Preprocessed for resizing and normalization to feed the DenseNet model

Solution

  • Trained a DenseNet-based deep learning model for multi-class image classification
  • Built a Flask-based web app with HTML/CSS interface
  • Users can upload an image and receive the top 4 predicted disease classes with probabilities in real time
  • Packaged model and app for end-to-end deployment, enabling practical use outside notebooks

Model Performance

  • Accuracy: 85.9% on 6,021 test images (5,175 correct predictions)
  • Provides immediate, interpretable predictions for users

Impact

  • Provides a user-friendly tool for preliminary skin anomaly detection
  • Translates a complex ML model into an accessible, actionable application for real-time use

Focus

Computer vision, deep learning, real-time classification, end-to-end deployment

Tools

Python, TensorFlow/Keras, DenseNet, Flask, HTML, CSS
